Exact Product Decisions
What I would do with the current player card, specifically.
Ship direction
Keep on first screen
Event title, progress count, title + artist in every cell, one huge bingo CTA.
Move out of first screen
Resync, text scale, advanced display preferences, hybrid explanation copy, validation detail, help links.
Typography rule
Bold title first; muted artist second; no metadata badges inside the main scan path unless essential.
  • Remove `Now Playing` from the first screen entirely and let the grid claim that space.
  • Keep artist always visible in every square, because one real competitor proves it can still read cleanly.
  • Let the card occupy almost all vertical space after the header, matching the strongest competitor pattern.
  • Preserve Tempo’s richer trust tools, but only inside the bottom sheet so the first read stays obvious.
  • In landscape, stop stacking everything vertically. Split the card and the action rail so the grid stays big.
